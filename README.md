# YOLO26s Object Detection

## Описание проекта

Данный проект посвящен решению задачи обнаружения объектов на изображениях с использованием архитектуры **YOLO26s**. В рамках проекта реализован полный цикл обучения модели компьютерного зрения: от анализа исходных данных и подготовки датасета до обучения модели, оценки качества и формирования итогового файла с предсказаниями.

Основной целью проекта является построение модели, способной точно определять положение и класс объектов на изображениях, а также исследование влияния различных этапов подготовки данных и настройки процесса обучения на итоговое качество детекции.

---

# Основные этапы проекта

В ноутбуке последовательно реализованы следующие этапы:

- загрузка и подготовка исходного датасета;
- анализ распределения классов;
- исследование размеров объектов и ограничивающих прямоугольников (Bounding Boxes);
- визуализация изображений и разметки;
- создание воспроизводимой среды с фиксированными значениями `random seed`;
- стратифицированное разделение выборки на обучающую и валидационную с использованием `MultilabelStratifiedKFold`;
- автоматическое формирование структуры датасета в формате YOLO;
- генерация файла конфигурации `data.yaml`;
- настройка аугментаций изображений с использованием `Albumentations`;
- обучение модели **YOLO26s**;
- анализ процесса обучения;
- построение графиков изменения метрик;
- выполнение инференса на тестовой выборке;
- генерация итогового файла `submission.csv`.

---

# Анализ данных

Перед обучением модели был проведен анализ исходного датасета.

В рамках исследования были выполнены:

- визуализация примеров изображений;
- анализ распределения объектов по классам;
- исследование количества объектов каждого класса;
- анализ размеров ограничивающих прямоугольников;
- проверка корректности разметки;
- исследование структуры датасета.

Полученная информация использовалась при выборе стратегии разделения данных и настройке процесса обучения.

---

# Подготовка датасета

Одним из важных этапов проекта является подготовка данных к обучению.

Для сохранения распределения всех классов используется алгоритм `MultilabelStratifiedKFold`, позволяющий сформировать более сбалансированную обучающую и валидационную выборки по сравнению со случайным разделением.

Для формирования структуры датасета используются **symbolic links**, благодаря чему отсутствует необходимость копирования большого количества изображений, уменьшается занимаемый объем памяти и ускоряется подготовка данных.

После формирования структуры автоматически создается конфигурационный файл `data.yaml`, необходимый для обучения модели.

---

# Обучение модели

Для решения задачи используется архитектура **YOLO26s**.

Обучение производится на предварительно обученных весах (**pretrained weights**) с последующим дообучением на рассматриваемом датасете.

Во время обучения выполняются:

- сохранение лучших весов модели;
- оценка качества на валидационной выборке;
- построение истории обучения;
- анализ изменения основных метрик.

---

# Аугментации

Для повышения способности модели к обобщению используется библиотека **Albumentations**.

В проекте применяется набор геометрических и цветовых преобразований изображений, позволяющий увеличить разнообразие обучающих данных и повысить устойчивость модели к различным условиям съемки.

---

# Инференс

После завершения обучения производится загрузка лучших весов модели и выполнение инференса на тестовой выборке.

Полученные предсказания автоматически преобразуются в формат соревнования и сохраняются в файл **submission.csv**.

В ходе экспериментов также исследовалось влияние значения **confidence threshold** на итоговое качество модели. По результатам проверки оптимальным оказалось значение **0.001**, которое обеспечило наилучший результат на публичной таблице лидеров.

# Запуск проекта

1. Скачать исходный датасет.
2. Поместить его в папку `data`.
3. Установить необходимые зависимости:

```bash
pip install -r requirements.txt
```

4. Открыть ноутбук `notebooks/yolo_object_detection.ipynb`.
5. Последовательно выполнить все ячейки.
