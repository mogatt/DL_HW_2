# YOLO Object Detection

Проект компьютерного зрения для обнаружения объектов на изображениях с использованием модели YOLO.

## Цель проекта

Обучить модель детекции объектов, проанализировать качество её работы и получить предсказания на тестовой выборке.

## Что выполнено

В рамках проекта были выполнены:

- анализ исходного датасета;
- исследование распределения классов;
- анализ размеров размеченных объектов;
- подготовка YOLO-разметки;
- стратифицированное разделение данных;
- создание конфигурации `data.yaml`;
- обучение модели YOLO;
- настройка аугментаций;
- анализ метрик и процесса обучения;
- инференс на тестовых изображениях;
- формирование итогового файла с предсказаниями.

## Используемая модель

В проекте используется модель семейства YOLO из библиотеки Ultralytics.

## Метрики

Для оценки качества модели используются:

- Precision;
- Recall;
- mAP@0.5;
- mAP@0.5:0.95.
